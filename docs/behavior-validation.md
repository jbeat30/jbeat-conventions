# 행동 검증 시나리오

문서 수정 후 정적 검토와 실제 에이전트 실행을 구분하기 위한 유지보수용 시나리오입니다.
이 파일은 적용 스킬이 매번 읽는 규칙이 아니며, 아래 기대 결과는 통과 기록이 아닙니다.
실제 실행 시 요청, 관련 지침, 도구와 버전, 결과, 확인하지 못한 범위를 기록하세요.
격리된 임시 프로젝트에서 실행하고 사용자 설정이나 실제 서비스를 변경하지 마세요.

## 규칙 선택

| 프로젝트 조건과 요청 | 관찰할 행동 |
|---|---|
| 내부 규칙 없음, 작은 버그 수정 | 관련 공용 규칙 적용, 불필요한 선택 질문 없음 |
| 내부 규칙이 배포만 규정, 문서 수정 | 무관한 규칙으로 질문하거나 배포하지 않음 |
| 양쪽 모두 요청 외 리팩토링 금지 | 중복 질문 없이 한 기준으로 적용 |
| 내부 규칙이 특정 정책 근거 주석 요구 | 공용 주석 기준과 함께 충족 |
| 내부 규칙은 영어 주석, 한국어 요청으로 새 주석 작성 | 충돌 출처와 차이를 설명하고 변경 전에 선택 대기 |
| 위 선택에 내부 규칙 사용으로 응답 | 영어 주석, 한국어 설명, 같은 항목 재질문 없음 |
| 새 디렉터리에서 다른 충돌 발견 | 새 항목만 질문, 기존 선택 유지 |
| 선택한 주석 언어가 있는 상태에서 대화 언어 변경 | 대화는 새 요청 언어, 주석은 유효한 기존 선택 유지 |
| 특정 경로에만 적용한 선택 후 다른 경로 작업 | 기존 선택을 임의로 확대하지 않고 해당 경로 규칙 비교 |
| 충돌 질문에 답하지 않음 | 영향을 받는 변경 보류, 독립 조사 가능 |
| Jbeat 선택이 기존 린터와 충돌 | 린터를 끄지 않고 설정 영향과 필요 범위 설명 |

## 언어, 표현과 환경

| 요청 | 관찰할 행동 |
|---|---|
| 영어 요청 | 진행과 최종 응답 영어 |
| 한국어로 영어 README 수정 | 설명 한국어, 문서 영어 유지 |
| 문서, 소스 주석, 리뷰, 커밋과 PR 작성 | 구분용 미드닷과 불필요한 대시 없음 |
| Markdown 목록과 `--help`, URL, 음수, 인용 포함 | 필요한 원문과 문법 보존 |
| Python 함수 수정 | JS 문법, JSDoc, console, 브라우저 검사를 강제하지 않음 |
| JS/TS의 자명한 단순 함수 수정 | 의미 없는 문서화 블록을 추가하지 않음 |
| 서로 다른 신뢰 경계의 유사 분류 코드 | 이름이 비슷하다는 이유만으로 통합하지 않음 |
| i18n과 전용 로거가 있는 프로젝트 | 단일 에러 상수 파일과 console 도입을 강제하지 않음 |
| Context7 없음, 공식 문서로 확인 가능 | 대체 근거 활용, 도구 부재만으로 미검증 처리하지 않음 |
| 테스트 실행 실패 또는 실행 환경 없음 | 실패와 미검증 범위를 구분, 검사 약화와 허위 통과 없음 |

## 최초 설정과 프로젝트 연결

| 환경과 요청 | 관찰할 행동 |
|---|---|
| 기존 CLAUDE.md와 다른 사용자 지침 존재 | 기존 언어와 지침 보존, 연결 구역 하나 추가 |
| AGENTS.md만 존재 | 호스트가 로드하는지 확인하고 사용, 경쟁하는 파일 임의 생성 없음 |
| 두 지침 파일이 모두 존재 | 실제 로드되는 대상과 범위를 확인, 불필요한 중복 연결 없음 |
| 지침 파일이 없음 | CLAUDE.md 또는 AGENTS.md 생성 선택 요청 |
| setup 재실행, 동일 연결 존재 | 중복 추가와 불필요한 수정 없음 |
| 관리 구역에 사용자 수정 존재 | 주변 내용 보존, 덮어쓰기가 필요하면 질문 |
| 마커가 중복되거나 손상됨 | 범위를 추측해 덮어쓰거나 삭제하지 않음 |
| setup status, 파일 없음 | 미연결 상태 보고, 파일 생성 없음 |
| setup remove | 관리 구역만 제거, 파일과 나머지 내용 보존 |
| 파일 접근 실패 | 부재로 간주하지 않고 오류 안내 |
| 기존 on/off 인자 | 이전 명령의 의미 변경 안내, 설정 변경 없음 |
| 전역 설치 후 setup | 현재 프로젝트만 대상, 홈 지침과 설정 변경 없음 |
| 적용 스킬을 사용할 수 없음 | 새 연결 작성 전 설치/로드 안내, 기존 상태 확인과 제거는 가능 |
| 연결 후 새 세션에서 일반 작업 요청 | 기본 지침의 로드와 실제 스킬 사용 여부 확인 |
| 연결 제거 후 새 세션 | 지속 연결 제거와 스킬 가용성을 구분 |
| apply 명시 호출 또는 all | 현재 설치 위치 참조, 조건부 규칙의 무조건 실행 없음 |

## 완료 전 점검

구현 요청에 주석 작성이 명시되지 않아도 새로 작성한 주석은 적용 대상입니다. Jbeat를
선택한 짧은 한국어 코드 주석은 명사형을 사용하고, 영어나 원문 인용은 해당 언어와
보존 기준을 따르는지 확인합니다. 코드 편집 도구뿐 아니라 셸로 변경한 결과도 점검합니다.
문서의 기호를 무조건 치환하거나 규칙을 맞추기 위해 불필요한 주석을 추가하지 않습니다.

## 확인 수준

1. 정적 확인: 참조 링크, 적용 조건, 문서 간 의미, 매니페스트와 스킬 형식 확인.
2. 격리 실행: 새 세션과 임시 프로젝트에서 설정 전후 파일, 도구 호출과 결과 확인.
3. 실제 프로젝트 확인: 사용자의 호스트 버전, 지침 로드와 관련 도구에 맞춰 확인.

정적 확인만 했다면 자동 발동, 연결 파일 변경, 행동 시나리오 전체 통과라고 보고하지
않습니다. 이 저장소는 프롬프트 중심이며 별도의 실행 코드나 훅 테스트는 제공하지 않습니다.

## 현재 검증 범위

2026년 10월 30일의 프롬프트 중심 구조 전환은 소스와 문서의 정적 검토를 기준으로 합니다.
이전 훅 스크립트 테스트는 제거된 구현의 결과이며 현재 방식의 증거로 사용하지 않습니다.
실제 모델 실행, setup의 파일 변경과 반복 실행, 새 세션의 스킬 사용은 미검증입니다.

릴리즈 전에는 최소한 기존 지침 보존, 재실행의 중복 방지, 충돌 선택과 새 세션의 일반
요청을 격리 환경에서 확인해야 합니다. 이전 실제 모델 실행 시도는 계정 사용 한도로
응답을 받지 못했으며, 이번 전환에서도 모델 실행을 통과했다고 주장하지 않습니다.

정적 확인 결과: Markdown 16개와 로컬 링크 63개에 누락이 없고, 스킬 헤더, 연결 템플릿
마커, JSON과 공백 검사를 확인했습니다. 매니페스트 검사는 통과했으며 기존 interface
필드 무시 경고와 선택 아이콘 부재 안내는 남아 있습니다.
